# Pennywise — Student Expense Prediction & Budget Advisor

**Live Demo:** https://studentexpensepredictionbudgetadvisor-dx58njadhj5fstgdqscu9v.streamlit.app/

## Run on Windows
Open this folder in VS Code. In its terminal, run:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Data
The included CSV is synthetic sample data. The app accepts a CSV upload. For predictions and monthly outlooks, the data must contain suitable real columns and enough valid records. Do not describe sample data as real student records.
